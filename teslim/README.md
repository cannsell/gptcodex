# Mac için site dosyaları

[Reklam-Ajanslari-Mac.zip dosyasını indir](https://github.com/cannsell/gptcodex/raw/refs/heads/codex/mac-indirme-20261015/teslim/Reklam-Ajanslari-Mac.zip)

1. ZIP dosyasını Mac’inizdeki İndirilenler klasörüne kaydedin ve açın.
2. `reklam-ajanslari/01-Site/index.html` dosyasını Safari, Chrome veya Edge ile açın.
3. Kaynak proje `02-Kaynak-Kod`, ekran görüntüleri `03-Ekran-Goruntuleri`, üretim dosyaları `04-Yayina-Hazir` klasöründedir.

İnceleme sürümü Node.js veya sunucu kurulumu gerektirmez. Ajanslar ve projeler örnek içeriktir; formlar e-posta taslağı oluşturur.
